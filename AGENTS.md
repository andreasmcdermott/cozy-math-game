# Working in this project

Read [DESIGN.md](DESIGN.md) before changing gameplay or scope. It records the user's decisions, the learning contract, and current handoff status.

Use [README.md](README.md) for run and verification commands. Keep recipe data and pure math rules separate from presentation. Quantities use exact integers, 60 ticks per cup. Each order gets a fresh deterministic puzzle tray with a guaranteed addition solution and decoys. Test many generated puzzles, transfers within an attempt, rewards, and save migration. Errands are optional coin challenges and must never gate potion puzzles.

Keep all illustrated game assets local. Read the asset provenance document before replacing art. Render mathematical labels in code, not in generated pictures. Preserve large touch targets, keyboard play, reduced motion, and forgiving correction of mistakes.

After meaningful changes, update the handoff section in DESIGN.md with completed work, checks actually run, and outstanding limitations.
